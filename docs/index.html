🎉 Toast - Foundry VTT Modules

Toast is a Foundry VTT module system for creating and displaying full-screen celebration animations.

📦 Modules

Toast Player

Lightweight playback engine for displaying toast animations.

Manifest URL:
https://ever-onward-games.github.io/toast/toast-player/module.json

View manifest.json | GitHub Repository

Toast Studio

Professional animation studio for creating toast packages with visual editor and package manager.

Manifest URL:
https://ever-onward-games.github.io/toast/toast-studio/module.json

View manifest.json | GitHub Repository

🚀 Installation

In Foundry VTT, use the manifest URLs above to install the modules:

  1. Go to Add-on Modules
  2. Click Install Module
  3. Paste the manifest URL
  4. Click Install
