## What is Toast?

Toast is a Foundry VTT module that displays **synchronized full-screen celebrations** to all players in your game. Whether it's a critical hit, a boss kill, or a clutch heal, Toast makes memorable moments truly epic.

### Key Highlights

🤖 **AI-Generated Announcements** - Dynamic, contextual text generated by Claude or GPT
🎙️ **Text-to-Speech** - ElevenLabs integration for voice announcements
🎮 **Full-Screen Visuals** - Images, text, animations, and sounds
🔒 **Secure & Validated** - GM-validated permission system
🎯 **System-Agnostic** - Works with D&D 5e, Pathfinder 2e, or any game system

---

## Features

### 🤖 AI-Generated Announcements (v2.0.0)

Generate unique, contextual announcements powered by AI:

```javascript
await game.toast.showDynamicAI({
  prompt: "[triumphant] Epic fantasy narrator",
  actor: { name: "Alice", class: "Paladin", level: 8 },
  target: { name: "Ancient Dragon", cr: 24 },
  context: "finishing-blow",
  damageDealt: 89
});
```

**AI generates:**
> "With a mighty swing of her Holy Avenger, Paladin Alice delivers a devastating 89 damage blow, bringing the Ancient Dragon crashing down in defeat!"

**Supports:**
- Claude 3.5 (Sonnet, Haiku, Opus)
- OpenAI (GPT-4o, GPT-3.5, Custom GPTs, fine-tuned models)
- ElevenLabs v3 with tone control: `[angry]`, `[triumphant]`, `[gentle]`
- Hybrid API key system (GM shares or players provide their own)
- System-agnostic design (works with any game system)

### 🎨 Full-Screen Visuals

Display synchronized visuals to all players:

```javascript
game.toast.show([
  {
    type: "text",
    text: "CRITICAL HIT!",
    color: "#ff0000",
    fontSize: "100px",
    animation: {
      startX: window.innerWidth / 2 - 300,
      startY: window.innerHeight / 2 - 50,
      duration: 2
    }
  }
]);
```

**Element Types:**
- 📝 Text with custom fonts, colors, shadows
- 🖼️ Images from URLs or Foundry data
- 🎭 Token and actor avatars
- 🔷 Shapes (rectangles, circles)
- 🔊 Sound effects with volume, delay, loop controls
- 🎬 Custom CSS animations

[**→ See Sample Macros**](docs/EXAMPLES.md#basic-examples)

### 🎤 Announcer Packs

Switch between different voice narrators or languages:

```javascript
game.toast.show([
  {
    type: "sound",
    src: game.toast.getAnnouncerSound("double-kill.wav")
  }
]);
```

**GM switches announcer pack** → All macros use new voice automatically!

## API Reference (Quick)

### Core Methods

```javascript
// Show toast to all players (GM-validated)
game.toast.show(elements)

// Show toast locally (testing)
game.toast.showLocal(elements)

// Check permission
game.toast.hasPermission()
```

### Dynamic TTS

```javascript
// Template-based TTS
await game.toast.showDynamic(templateId, tokens, elements)

// AI-generated TTS
await game.toast.showDynamicAI(config)
```

### Templates

```javascript
// Register template
game.toast.templates.register(id, config)

// Render template
game.toast.templates.render(id, tokens)

// List templates
game.toast.templates.list(tag)
```

### Sound Utilities

```javascript
// Random sound (synchronized)
game.toast.randomSound(sources, options)

// Weighted random
game.toast.weightedRandomSound(soundsWithWeights, options)

// Get announcer sound
game.toast.getAnnouncerSound(filename)
```

## Example Macros

### Critical Hit with Sound

```javascript
game.toast.show([
  {
    type: "sound",
    src: game.toast.getAnnouncerSound("critical-hit.wav"),
    volume: 0.9
  },
  {
    type: "text",
    text: "CRITICAL HIT!",
    color: "#ff0000",
    fontSize: "100px",
    fontWeight: "bold",
    textShadow: "0 0 50px #ff0000",
    animation: {
      startX: window.innerWidth / 2 - 300,
      startY: window.innerHeight / 2 - 50,
      duration: 2
    }
  }
]);
```

### Boss Kill with AI (D&D 5e)

```javascript
const token = canvas.tokens.controlled[0];
const target = game.user.targets.first();

if (!token || !target) {
  ui.notifications.warn("Select your token and target!");
  return;
}

await game.toast.showDynamicAI({
  prompt: "[triumphant] Epic fantasy narrator with dramatic flair",
  actor: {
    name: token.name,
    class: token.actor.system.details.class,
    level: token.actor.system.details.level
  },
  target: {
    name: target.name,
    cr: target.actor.system.details.cr
  },
  context: "finishing-blow",
  elements: [
    {
      type: "text",
      text: "BOSS DEFEATED!",
      color: "#FFD700",
      fontSize: "80px",
      fontWeight: "bold",
      textShadow: "0 0 50px #FFD700",
      animation: {
        startX: window.innerWidth / 2 - 350,
        startY: window.innerHeight / 2 + 200,
        duration: 3
      }
    }
  ],
  fallbackTemplate: "boss-kill"
});
```

## System Compatibility

Toast works with **any game system** because of its system-agnostic design:

### D&D 5e
```javascript
actor: {
  name: token.name,
  class: token.actor.system.details.class,
  level: token.actor.system.details.level
}
```

### Pathfinder 2e
```javascript
actor: {
  name: token.name,
  class: token.actor.system.details.class.value,
  level: token.actor.system.details.level.value
}
```

### Custom Homebrew
```javascript
actor: {
  name: "Alice",
  faction: "Silver Ravens",
  "custom field": "any value"
}
```

The AI figures out what matters from your structured data!

## For Module Developers

Toast provides an API for other modules to register announcer packs:

```javascript
Hooks.once('ready', () => {
  if (game.toast && game.toast.registerAnnouncer) {
    game.toast.registerAnnouncer('my-epic-announcer', {
      name: 'Epic Movie Announcer',
      path: 'modules/my-module/sounds/announcer'
    });
  }
});
```
